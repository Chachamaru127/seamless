## 何を、なぜ

claudex で AI 同士がやりとりしても、人には次の2つが見えない。
1. この会話が今何をしているか。
2. 相手とのやりとりが、届いたか、読まれたか、失敗したか。

この機能は、Claude の入力欄の上に固定の帯を1本出して、この2つを一目で分かるようにする。
Codex 側は、Codex の画面に表示を置けるかを確かめてから決める（Open questions 1）。

## 見た目の決定事項（2026-10-03 立花さん）

見本: `out/ask-pro/20261003-claude-band/`（collapsed.html、expanded.html、common.css、sheet.png）。色と寸法はこの CSS を正とする。帯 #1d1d1b、角丸 12px、行の高さ 34px、文字 #e9e7e2、補足の灰 #8d8b85、作業中の点 #8070f0、緑 #38c68e、オレンジ #f9a437、赤 #fe3a52、相手の丸い札の地 #2a2a27。

- 暗い版。濃いチャコールの帯、フラット、角丸。色は状態を示すときだけ使う。
- 閉じた状態は1行。左に「今していること」と経過時間、右に相手の会社のロゴとやりとりの回数。
- 回数は、その会社の相手とのやりとりの総数（案A）。
- 回数の文字色は、その会社の相手との最新のやりとりの状態。赤は届かなかった、オレンジは届いたが未読、緑は既読。
- 既読は「相手が、その依頼の後に応答を始めた記録がある」こと。既読の色（緑）は、送り主の照合（6観点 spec の AC34）で確認済みの相手にだけ使う。
- ▸ で開くと、この会話の手順の履歴と、相手ごとのやりとりの一覧を出す。

## 受け入れ条件（AC）

- AC1: Claude Desktop アプリの Code タブで、入力欄の上に帯が1本だけ出る。（2026-10-05 改訂。立花さん「CLIは想定してない、アプリ版のUI上で出してほしい」。元の依頼（2026-10-02「APP画面にUIを追加」）に戻した。ターミナルは対象外で、描けても描けなくてもよい）
- AC2: 閉じた状態の左に、この会話の今の状態を1行の日本語で出す。状態の種類は少なくとも、指示を読んでいる、考えている、道具を使っている（何のためかを含む）、承認待ち、返事を書いている、待機中。経過時間を秒単位で更新する。
- AC3: 右に、やりとりのある会社ごとにロゴと回数を出す。やりとりのない会社は出さない。（2026-10-05 改訂。回数は `↑送った数(未確認) ↓受け取った数(未読)` の形。[design-v2.md](design-v2.md) の「右側」）
- AC4: 回数の色は AC の定義どおり（赤、オレンジ、緑）。状態を観測できないときは灰色にし、「未確認」と分かるようにする。（2026-10-05 改訂。立花さんの指示で、色の代わりに括弧の数で未確認と未読を、`!` で届かなかったことと照会の失敗を示す。詳細は開いた状態の「問題」の欄）
- AC5: ▸ で開くと、この会話の履歴（指示、各手順の結果の印と所要時間）と、相手ごとのやりとり（相手の名前、作業場所、本文の冒頭、状態）を出す。✓ 完了、✗ 失敗、⊘ 拒否、■ 中断の印を使う。
- AC6: 帯は表示だけを行う。Claude の動作、道具の呼出し、承認の判断、送信を変えない。
- AC7: 帯は会話の本文、思考、認証値をファイルや外部へ保存も送信もしない。やりとりの状態は claudex の照会結果からだけ得る。
- AC8: 帯の文言から制御文字と不可視文字を取り除いてから描く。
- AC9: claudex の照会に失敗しても、帯の左半分（今していること）は動き続け、右半分は灰色で「未確認」を出す。
- AC10: 取り込んだ外部の部品の出典とライセンス（whats-agent-doing、MIT）を記録する。

## Open questions

1. Codex の画面に同じ情報を出せるか（plugin extensions の会話横パネル）。Codex 会話へ問い合わせ中。出せない場合、今回は Claude 側だけにする。
2. （2026-10-05 決定）ロゴは、2026-10-03 に合意した見本（`out/ask-pro/20261003-claude-band/`）の形の単色の印を Svg 要素で描く（Desktop は Svg を描ける。mods reference の Elements）。元の依頼（2026-10-02「openaiとアンソロピック社のロゴと、ロゴの隣に数字」）に合わせる。文字の略号は Svg を描けない場所の代わりだけに使う。
3. 同じ会社の相手が複数いるとき、回数と色を会社でまとめるか、相手ごとに分けるか。案: 閉じた状態は会社でまとめ、開いた状態で相手ごとに分ける。
