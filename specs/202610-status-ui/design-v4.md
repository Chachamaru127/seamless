## 決めたこと

| 点 | 第3版 | 第4版 | 理由 |
|---|---|---|---|
| 相手の表し方 | 会社（Codex、Claude）のロゴと色のタイル | 会話が主。名前は作業場所のフォルダ名、worktree なら「repo · worktree 名」（peerName）。会社と短い id は小さな灰色の添え書き（peerBadge） | 垣根を感じさせない。相手は「どの仕事をしている会話か」で見分ける |
| 色 | 会社の色（Codex 緑、Claude 橙）が常に出る | 色は状態にだけ使う。済んだ段は緑、今の段は橙、まだは輪郭、届かなかったは赤。会社の印は両社とも同じ灰色の丸に Cx / Cl（avatarSvg） | 色が意味を 1 つしか持たないので読み間違えない |
| 1 行の右 | 会社ごとに ↑↓ の数と、一番大事な言葉 | 一番大事な相手 1 つのチップ: 灰色の印、会話名、段の軌跡（trackSvg の点 4 つ）、今の段と経過時間。続けて ! と ×n（相手の数） | 数より「どこで止まっているか」が先。全体は ×n でパネルへ |
| パネル | なし（▸ で帯の下に展開するだけ） | ×n で右のパネル「チーム」（id seamless-team）。見出しは「チーム · n 会話」と直近 24 時間の集計（送った、受け取った、未読、届かなかった）。相手ごとのカード: 印、会話名、添え書き、フォルダと動いている／止まっている、最新の時刻。新しい依頼 3 件を本文の冒頭（送った依頼だけ）と段の列で。最後に目的と計画の位置、凡例 | やりとりが多いときに帯を伸ばさない。参考 mod の担当パネルと同じ操作感 |
| ▸ の展開 | やりとり欄の見出しは会社名とロゴ | 見出しは会話名と添え書き。中身は同じ | 帯とパネルで名前の付け方をそろえる |
| 通知の主語 | 「Codex から返信が届きました」 | 「<会話名> から返信が届きました」 | 主語も会話 |
| 受け取った依頼の本文 | 出さない | 出さない | 照会は本文を持たない決まり（立花さん判断 2026-10-05） |

## 材料

- 相手の名前: 照会の `candidates[].cwd`。`.claude/worktrees/<name>` を含むときは `<repo> · <name>`。cwd が無いときは「作業場所は未確認」。
- 段の軌跡: 第3版の stepsOf の state（done / now / todo / bad）をそのまま点にする。
- パネルの開閉: `$.ui.panes()`、`$.ui.open({ id, title })`、`$.ui.close({ id })`。描画は `ui.render` の `Pane`（requestId seamless-team）。
- 集計: summaryOf（送った、受け取った、未読、届かなかった）。会社ごとの集計（talliesOf）は問題の検出にだけ残す。
